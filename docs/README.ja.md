# Checkbox Reminder

[English](../README.md) | **日本語** | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

チェックボックスの横の時計ボタンから、カレンダーと時刻のメニューでリマインダーを設定できます。時刻になるとデスクトップ通知が届き、サイドバーで期限の近い順に一覧できます。

## できること

- 未完了のチェックボックスの左に**時計ボタン**が出ます（編集ビューと閲覧ビューの両方）。押すと、**日付はカレンダー**、**時刻はメニュー**（時と分）で選べます。「1時間後」「今夜20:00」「明日9:00」のボタンもあります。
- **時刻を指定しない**にチェックを入れると、日付だけを保存します。通知は設定の時刻（初期値は09:00）に出ます。今日の日付だけで設定した場合は、すぐには通知しません。
- リマインダーは、タスクの中にふつうの文字で書き込まれます。プラグインがなくても読めます。

  ```
  - [ ] 牛乳を買う ⏰ 2026-10-26 09:00
  ```

- 時刻になると、**デスクトップ通知**が出ます（Windows、macOS、Linux）。押すとノートが開きます。Obsidianの中にも、**完了**・**再通知**・**開く**のボタン付きのメッセージを出せます。
- 右サイドバーの**リマインダー一覧**に、Vault内の未完了のリマインダーが期限の近い順に並びます。「期限切れ」「今日」「明日」「7日以内」「それ以降」に分かれます。チェックを入れるとタスクが完了し、時計を押すと時刻を変更でき、項目を押すとノートが開きます。
- Obsidianを閉じている間に時刻が過ぎたリマインダーは、次に起動したときに知らせます。
- 設定、コマンド、メッセージは、英語、日本語、簡体字中国語、繁体字中国語、韓国語、スペイン語、フランス語、ドイツ語で表示できます。最初はObsidianの言語に合わせ、設定で変更できます。

## 注意

- 通知には、Obsidianが起動している必要があります。スマホやタブレットではシステムの通知は出ません。代わりに、Obsidianを開いている間にメッセージを出します。
- 一覧やメッセージから完了にすると、ノートのチェックボックスにもチェックが入ります。

## Vault内のノートの読み取り

リマインダーを探すために、Vault内のノートの一覧を確認し、チェックボックスのあるノートを読みます。探すのは、チェックボックスと ⏰ の日付がある行だけです。どこにも送信せず、すべて端末の中で処理します。

## ネットワークの利用

ありません。オフラインで動き、データも集めません。
